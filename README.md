- **Perception:** NVIDIA Jetson Orin NX, Intel RealSense, YOLO-based object detection, and target tracking.
- **Motion:** BLDC motor integration and VESC-based control for a tracked robotic platform.
- **Software:** Python, Kalman filtering, WebSocket communication, and remote operator interaction.
- **Safety:** watchdog supervision, KILL / emergency-stop logic, and system-level fault handling.
- **Documented test observations:** approximately **20–25 FPS** during perception testing, **68/75** valid system tests, and **26–28/30** successful real-environment trials, as reported in the project documentation.
